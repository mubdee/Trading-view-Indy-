**DAY (1) 2026-11-27 — เบาลง + ทุก TF เห็นเหมือนกัน**
1. **Engine คำนวณเฉพาะวันเทรดปัจจุบัน** (เริ่ม 18:00 NY + แท่งอุ่นเครื่องสำหรับ swing) · input `วิเคราะห์ย้อนหลัง (วันเทรด)` 1-3 · กราฟ ≥ M30 ใช้อย่างน้อย 150 แท่ง
2. **เลเวล MSNR H1/H4 + OB H1/H4 คำนวณใน TF นั้นเอง** (ทะลุ / Flip RBS-SBR / Fresh / Mitigated) → M1 · M5 · M30 ได้เลเวลชุดเดียวกัน · Next R/S · TP · กฎ Q4 ของ QT ไม่ขัดกันข้าม TF
3. **request TF ใหญ่รวมเป็นตัวเดียวต่อ TF** (เลเวล + Storyline + OB + Sweep + SMT swing) · 16 → 10 request · เส้นเลเวล HTF วาดเฉพาะที่แสดงตอนแท่งสุดท้าย · calc_bars_count 3000
4. **โซนที่กำลังรอ Sweep แสดงเส้นเสมอ** (`◎ โซน`) แม้เลเวลถูกแตะแล้ว
5. **โซนรอ Sweep หมดอายุเป็นชั่วโมง** (ค่าเริ่ม 3 ชม. ทุก TF) + **ยกเลิกเมื่อราคาปิดห่างเลเวลเกิน 3 ATR** ทางทิศเทรด
6. **Flip จากจุดเข้าที่จาง = จางด้วย** (`· จากจุดจาง` · ไม่ส่ง Alert)
7. ป้ายขอบขวา: ระยะห่างปรับได้ (`% ของกรอบราคา` ค่าเริ่ม 3) + ป้ายข้อความซ้ำที่ติดกันแสดงอันเดียว · Dashboard จุดเข้าล่าสุดสั้นลง

**DAY (2) 2026-11-27 — แก้จากการตรวจกราฟ M15**
1. ช่วงอุ่นเครื่องเก็บ swing อย่างเดียว ไม่วาดป้าย Sweep / SMT ของเมื่อวาน
2. ระยะโซนใช้ ATR H1 (Sweep ใกล้เลเวล 0.3 · ยกเลิกเมื่อวิ่งออก 1.0) → เท่ากันทุก TF ≤ H1
3. แท่งอุ่นเครื่องข้ามช่วงพัก 17:00-18:00 NY และเสาร์-อาทิตย์ (วันจันทร์มี swing ให้ Sweep ตั้งแต่ต้นวัน)
4. ขึ้นวันใหม่ 18:00 NY ขณะเปิดกราฟ → ล้างจุดเข้า / ป้าย / โซนของวันที่เกินช่วง
5. QT "ไม่ชัด → ข้ามรอบนี้" · แถบ Quarter ไม่วาดช่วงอนาคต (ยังอยู่ใต้กราฟ)
6. ป้ายขอบขวาห่าง 3.5% + จัดกลุ่มป้ายให้กึ่งกลางตรงเส้น

**DAY (3) 2026-11-27 — QT แม่นขึ้น (วัน · 90m · Micro)**
1. Efficiency Ratio ของ Q1: กรอบแคบ หรือ ER < 0.3 = A ↔ · Q1 วิ่งแรง (D) ต้อง ER ≥ 0.5
2. หลอก (M) ต้องกวาดเกินกรอบเก่า ≥ 0.15 × เกณฑ์กรอบแคบ · Q1 ไซด์เวย์ปิดเกินนิดเดียว = ยัง A · ใช้กับ Q2 ด้วย
3. Q1 หลอกแต่ Q2 ปิดทะลุต่อทางเดียวกัน → นับเป็น X (กวาดแล้ววิ่งต่อ)
4. แตะแถว QT ใน Dashboard ดูเหตุผลที่ตัดสิน

**DAY (4) 2026-11-27 — QT Micro บนกราฟ:** แถบ Quarter แถวที่ 3 (ติดราคา · 22.5 นาที × 4 ของ 90 นาทีปัจจุบัน · TF ≤ M5) + เส้น `TO Micro` · เปิด/ปิดได้ในหมวด QT
