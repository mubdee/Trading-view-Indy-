# SMC CB — Top-down BOS Cascade

ไฟล์สคริปต์: [`smc-cb.pine`](./smc-cb.pine) (Pine Script v6) · แดชบอร์ด / หน้าตาเหมือน SFP Pro X v2

## วิธีใช้
1. เปิดไฟล์ `.pine` → กด **Raw** → คัดลอกทั้งหมด
2. TradingView → Pine Editor → วางโค้ด → **Add to chart**
3. เปิดบนกราฟ **M5** (หรือ M1 ถ้าใช้วิธีเข้าแบบ Confirm)

## ลำดับเงื่อนไข (ตัวอย่างฝั่ง Sell)
1. **Bias D1** — Structure (BOS ล่าสุดบน D1 ปิดด้วยเนื้อ) + Candle (แท่งเมื่อวาน) · ขัดกัน = งดเทรด
2. **Structure TF** — ไล่หา H4 → H1 → M30 → M15 · TF แรกที่ทะลุ swing ด้วยเนื้อเทียนตาม Bias
3. **Confirm TF** (ถัดลง 1 ขั้น) — การทะลุครั้งล่าสุดปิดด้วยเนื้อ = TP ที่ Low ของขา · ไส้กวาดแล้วปิดกลับ = TP ที่ POI ก่อนถึง Low
4. **IDM** (Entry TF = ถัดลงอีก 1 ขั้น) — swing เล็กล่าสุดของชุดที่ส่งแรงทะลุ BOS
5. **โซนเข้า (M5)** — OB / Supply ในขา · Fib ต้นขา (1) → ปลายขา (0)
   - โซน 1 แตะ ≥ 0.618 · ถ้าใช้ไม่ได้หรือโดน SL → โซน 2 ≥ 0.786
   - SL เลยขอบนอกโซน + buffer
6. **ยกเลิก** — ปิดเลยต้นขา · Structure TF ทะลุสวน · Bias เปลี่ยน · ถึง TP ก่อนเข้า
