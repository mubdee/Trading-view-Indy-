# SMC CB — สเปกเซ็ตอัพ (ยังไม่มีโค้ด)

> สถานะ: สเปกสำหรับตรวจก่อนเขียนโค้ด · Dashboard และการแสดงผลบนกราฟให้เหมือน SFP Pro X
> อัปเดต 2026-11-20: เพิ่มสเปก POI = **Key Level**

## 1) Bias และ BOS แบบไล่ TF
1. **D1** ให้ Bias ขึ้น/ลง
2. หา BOS / CHoCH ที่ **ปิดด้วยเนื้อเทียนเท่านั้น** ไล่ H4 → H1 → M30 → M15
3. ลง TF ถัดไป 1 ขั้น:
   - ปิดเนื้อทะลุด้วย → TP ที่ low
   - ทะลุแค่ไส้ → TP ที่ POI ก่อนถึง low แล้วรอสัญญาณใหม่
4. ลงอีก 1 TF เพื่อหา **IDM** (high ของขาที่ส่งให้เกิด BOS)
5. ถ้าโซนแรกโดน SL → หาโซนที่ 2 ที่เลย 0.786 (เช่น Supply ถัดไป)

### กฎยืนยันข้าม TF
- TF ใหญ่ทะลุด้วยเนื้อ → TF ถัดไปต้องทะลุด้วยเนื้อด้วยถึงจะเข้า (เช่น H4 เนื้อ แต่ H1 แค่ไส้ = น่าจะกลับตัว → ไม่เข้าโซนนั้น)
- Cascade: TF ยืนยันทำ body break ใหม่ (เช่น setup M15 แล้ว M5 ทำ low ใหม่) → เช็คที่ TF ถัดลงไป (M3) · M3 แค่ไส้ = ใช้โซนเดิม ขาใหม่กลายเป็น IDM/LQ · เข้าที่ Supply + QM M3 (+ SBR M1)
- มีตัวเลือกแสดง setup ทุก TF หรือเลือก TF เดียว

## 2) POI = Key Level (เพิ่ม 2026-11-20)
**Key Level = ระดับ MSNR ที่ซ้อนอยู่ใน OB หรือ Demand/Supply ทุก TF ที่อยู่ในชุด MSS / BOS เดียวกัน**

1. **หาโซนสะสมของรายย่อย (LQ)** — ช่วงราคาออกข้าง/กรอบที่ stop กองอยู่ ระหว่างราคาปัจจุบันกับ Key (ราคาต้องวิ่งผ่าน LQ ก่อนถึง Key)
2. **คัดโซน TF ใหญ่ (H1–H4)** — OB / Demand-Supply ที่เป็นต้นทางของขา BOS (เช่น OB ที่เกิดจาก Turtle Soup / sweep)
3. **ซูมเข้าไปในโซนนั้นบน LTF (เช่น M5)** — หาระดับ MSNR ที่อยู่ข้างใน:
   - **QML** = ไหล่ซ้ายของ Quasimodo (swing ก่อน HH/LL ที่ถูกกวาด)
   - **SBR / RBS** = body ของ swing ที่ถูกทะลุ
   - **A / V** = body ของ swing (ยอด/ก้นของ line chart)
4. **กติกาเลือก Key**
   - ระดับต้องยังไม่ถูกใช้ (Fresh · ราคายังไม่เคยแตะ)
   - ต้องซ้อนโซนทิศเดียวกัน **ทุก TF ที่อยู่ในชุด** (เช่น M5 QML อยู่ใน OB H1 และ OB H4)
   - **เลือกโซนสุดท้าย** = ระดับ Fresh ที่ลึกสุด ใกล้ต้นทางของขา (ตั้งให้เลือก "ใกล้ราคาสุด" ได้)
5. **เข้า** — Limit ที่ Key Level · SL เลยโซน/ปลายไส้ต้นทาง · TP ตามกฎข้อ 1

ตัวอย่างในภาพอ้างอิง: OB H4 (Turtle Soup) → กรอบ LQ H4 ด้านล่าง → ใน OB H4 บน M5 ได้ Key QML + Key SBR → ราคาวิ่งผ่าน LQ ขึ้นไปแตะ Key QML แล้วร่วง

## 3) การแสดงผล
