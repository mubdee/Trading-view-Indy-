# Sweep + MSS — ยืนยันโครงสร้างอย่างเดียว (MTF)

- ไฟล์หลัก: [`main/sweep-mss-main.pine`](./main/sweep-mss-main.pine)
- ไฟล์สำรองสำหรับแก้: [`sweep-mss-dev.pine`](./sweep-mss-dev.pine) (ชื่อบนกราฟ `Sweep + MSS DEV`)

ไม่มีจุดเข้า / SL / TP · แสดงเฉพาะโครงสร้าง

**v5 (MTF):** เปิดกราฟเล็ก เช่น M5 แล้วอินดี้ตรวจจับ Sweep + MSS บนแท่งของ TF ใหญ่ — ค่าเริ่มต้น M30 · H1 · H4 (เปิด/ปิด/เปลี่ยนได้ทีละตัว · TF ที่ไม่ใหญ่กว่ากราฟจะถูกข้าม)

1. **Sweep** — แท่ง TF ใหญ่ไส้เลย swing (ภายใน 60 แท่งของ TF นั้น) แล้วปิดกลับ · ห่างจากแท่ง swing ≥ 2 แท่ง · ป้าย `Sweep H1`
2. **ระดับ MSS** — จุดสูง/ต่ำสุดของขาที่ส่งราคาไป sweep (เส้นประระหว่างรอ)
3. **MSS ✓** — แท่ง TF ใหญ่ปิดด้วยเนื้อทะลุระดับภายใน 20 แท่ง · ไส้ทะลุแล้วปิดกลับ = แค่ sweep ระดับ MSS (รอต่อ · ป้ายบอก `หลัง sweep`) · ทำ High/Low ใหม่เลยไส้ sweep ก่อน = ยกเลิก
4. ใช้ค่าของแท่ง TF ใหญ่ที่ปิดแล้วเท่านั้น → ขึ้นบนกราฟ M5 ตอนแท่ง TF ใหญ่ปิด (ไม่ repaint)
5. ความหนาเส้น: TF1 บาง · TF2 กลาง · TF3 หนา · Dashboard แยกสถานะทุก TF

Alert: Bullish / Bearish Sweep · Bullish / Bearish MSS ✓ (รวมทุก TF) หรือ "Any alert() function call" (บอก TF ในข้อความ)
