# Sweep + MSS — ยืนยันโครงสร้างอย่างเดียว

- ไฟล์หลัก: [`main/sweep-mss-main.pine`](./main/sweep-mss-main.pine)
- ไฟล์สำรองสำหรับแก้: [`sweep-mss-dev.pine`](./sweep-mss-dev.pine) (ชื่อบนกราฟ `Sweep + MSS DEV`)

ไม่มีจุดเข้า / SL / TP · แสดงเฉพาะโครงสร้าง

1. **Sweep** — ไส้เลย swing แล้วปิดกลับ (swing ของ TF กราฟ ภายใน 60 แท่ง + swing ของ TF ใหญ่ เช่น H1) · แท่ง sweep ต้องห่างจาก swing ≥ 2 แท่ง · ป้ายบอก TF ที่ถูกกวาด เช่น `Sweep M30,H1`
2. **ระดับ MSS** — จุดสูง/ต่ำสุดของขาที่ส่งราคาไป sweep (ระหว่าง swing ที่ถูกกวาดกับแท่ง sweep)
3. **MSS ✓** — ค่าเริ่มต้น (v3): แท่งที่ปิดด้วยเนื้อทะลุระดับภายใน 20 แท่ง = MSS · แท่งที่แค่ไส้ทะลุแล้วปิดกลับ = sweep ระดับ MSS (ป้าย `sweep`) รอต่อ · โหมดอื่นให้เลือก: แท่งทะลุเป็น Displacement (body ≥ 1 ATR) = ยืนยันทันที · ไม่งั้นแท่งถัดไปต้องไม่ปิดกลับเลยระดับเกิน 0.1 ATR · เลือกแบบเข้ม "แท่งถัดไปปิดเลย High/Low แท่งทะลุ" ได้ · ปิดกลับ = แค่ sweep · ทำ High/Low ใหม่เลยไส้ sweep ก่อน = ยกเลิก
4. ระหว่างรอยืนยัน: เส้น MSS ประ + ป้าย `MSS? รอยืนยัน`
5. เกรด ★ (สูงสุด ★★★): กวาด swing TF ใหญ่ · Displacement · มี FVG ในขา MSS (วาดกล่อง FVG)
6. ตัดสินเฉพาะแท่งที่ปิดแล้ว (v2) — แท่งที่ยังวิ่งไม่ทำให้ setup ถูกยกเลิก
7. Sweep ที่ไม่เกิด MSS: ลบทิ้ง (เลือกแสดงจางได้)

Alert: Bullish / Bearish Sweep · Bullish / Bearish MSS ✓ (หรือ "Any alert() function call")
