# สรุปเงื่อนไข RJB & SFP (สำหรับแก้ทีละแท่ง)

ไฟล์โค้ด: `RJB_SFP.pine` — ทุกเงื่อนไขในไฟล์นี้มีรหัส (เช่น `[R2]`) ตรงกับคอมเมนต์ในโค้ด ค้นหารหัสในโค้ดแล้วแก้ได้ทันที

> หมายเหตุ: โค้ดต้นฉบับของ Milana Trades ไม่ได้ถูกคัดลอกมา อินดิเคเตอร์นี้เขียนขึ้นใหม่ตามแนวคิด Rejection Block / Swing Failure Pattern ทั่วไป ค่าเริ่มต้นอาจต่างจากต้นฉบับ ให้ปรับด้วยโหมด Debug

## ลำดับการทำงานในแต่ละแท่ง

ทุกครั้งที่ปิดแท่งใหม่ (แท่งปัจจุบัน = แท่ง 0) สคริปต์ทำตามลำดับนี้:

| ลำดับ | ขั้นตอน | รหัส |
|---|---|---|
| 1 | หา pivot ที่เพิ่งยืนยัน (แท่งที่อยู่ย้อนหลัง `pvRight` แท่ง) | P1 |
| 2 | ตรวจ SFP ของแท่งปัจจุบันกับ swing ทั้งหมดที่เก็บไว้ | S1–S6 |
| 3 | เก็บ swing ใหม่จากข้อ 1 ลงในรายการ | P1 |
| 4 | อัปเดตโซน RJB เดิม: ยกเลิก / แตะ / ยืดโซนไปทางขวา | R5, R6 |
| 5 | ถ้า pivot ใหม่ผ่านเงื่อนไข ให้สร้างโซน RJB ใหม่ | R1–R4, R7 |
| 6 | ส่ง alert | — |

## 1) Pivot / Swing `[P1]`

- **Swing High**: high ของแท่ง X สูงกว่า high ของ `pvLeft` แท่งทางซ้าย และ `pvRight` แท่งทางขวา
- **Swing Low**: low ของแท่ง X ต่ำกว่า low ของ `pvLeft` แท่งทางซ้าย และ `pvRight` แท่งทางขวา
- เราจะรู้ว่าเป็น pivot หลังจากผ่านไป `pvRight` แท่งเท่านั้น (ค่าเริ่มต้น 3 แท่ง) โซนกับ swing จึงไปโผล่ย้อนหลัง
- ค่าเริ่มต้น: ซ้าย = 5, ขวา = 3

| อยากให้… | ปรับ |
|---|---|
| เจอ swing บ่อยขึ้น / เล็กลง | ลด `pvLeft` |
| ยืนยันเร็วขึ้น (แต่หลอกบ่อยขึ้น) | ลด `pvRight` |

---

## 2) Rejection Block (RJB)

ความหมาย: แท่งที่เป็น swing และ**มีไส้ยาว** แสดงว่าราคาถูกปฏิเสธแรง โซนคือ "ส่วนไส้เทียน"

### คำนิยามของแท่ง pivot
- `Body` = |Close − Open|
- `Range` = High − Low
- `ไส้บน` = High − max(Open, Close)
- `ไส้ล่าง` = min(Open, Close) − Low

### Bearish RJB (โซนแนวต้าน) — ต้องผ่าน**ทุกข้อ**

| รหัส | เงื่อนไข | ค่าเริ่มต้น |
|---|---|---|
| R1 | แท่งนั้นเป็น **Swing High** | — |
| R2 | `ไส้บน ≥ wickBodyMin × Body` | 1.5 เท่า |
| R3 | `ไส้บน / Range ≥ wickRangeMin` | 0.5 (ไส้ ≥ 50% ของแท่ง) |
| R4 | (ถ้าเปิด) แท่งนั้นเป็นแท่งแดง Close < Open | ปิด |
| R7 | โซน = **max(Open, Close) ถึง High** | — |

### Bullish RJB (โซนแนวรับ) — ต้องผ่าน**ทุกข้อ**

| รหัส | เงื่อนไข | ค่าเริ่มต้น |
|---|---|---|
| R1 | แท่งนั้นเป็น **Swing Low** | — |
| R2 | `ไส้ล่าง ≥ wickBodyMin × Body` | 1.5 เท่า |
| R3 | `ไส้ล่าง / Range ≥ wickRangeMin` | 0.5 |
| R4 | (ถ้าเปิด) แท่งนั้นเป็นแท่งเขียว Close > Open | ปิด |
| R7 | โซน = **Low ถึง min(Open, Close)** | — |

### สิ่งที่เกิดกับโซนในแต่ละแท่งหลังจากนั้น

| รหัส | เหตุการณ์ | Bearish RJB | Bullish RJB | ผลลัพธ์ |
|---|---|---|---|---|
| R5 | **แตะโซนครั้งแรก** | High ≥ ขอบล่างโซน | Low ≤ ขอบบนโซน | เปลี่ยนเป็นสีเทา + alert (หรือลบทิ้งถ้าปิด `keepTouched`) |
| R6 | **ยกเลิกโซน** (โหมด Close) | Close > High ของโซน | Close < Low ของโซน | ลบโซน |
| R6 | **ยกเลิกโซน** (โหมด Wick) | High > High ของโซน | Low < Low ของโซน | ลบโซน |
| — | ไม่เกิดอะไร | — | — | ยืดโซนไปถึงแท่งปัจจุบัน |

- เก็บไว้สูงสุด `maxRJB` โซนต่อฝั่ง (ค่าเริ่มต้น 10) โซนเก่าสุดจะถูกลบ
- โซนเริ่มตรวจตั้งแต่แท่ง**ถัดจาก**แท่งที่ยืนยัน pivot

## 3) Liquidity Grab / SFP (Swing Failure Pattern)

ความหมาย: ราคา**แทงไส้ทะลุ** swing เดิมเพื่อกวาด stop/liquidity แต่**ปิดแท่งกลับเข้ามา**

### Bearish SFP (กวาดเหนือ Swing High) — ตรวจบนแท่งปัจจุบัน

| รหัส | เงื่อนไข | ค่าเริ่มต้น |
|---|---|---|
| S1 | `High > ราคา swing high` ที่ยังใช้ได้ | — |
| S2 | `High − ราคา swing ≥ sfpMinPenAtr × ATR(14)` | 0 (ทะลุนิดเดียวก็นับ) |
| S3 | `Close ≤ ราคา swing high` (ปิดกลับใต้) | — |
| S4 | (ถ้าเปิด) แท่งปัจจุบันเป็นแท่งแดง | ปิด |

### Bullish SFP (กวาดใต้ Swing Low)

| รหัส | เงื่อนไข | ค่าเริ่มต้น |
|---|---|---|
| S1 | `Low < ราคา swing low` ที่ยังใช้ได้ | — |
| S2 | `ราคา swing − Low ≥ sfpMinPenAtr × ATR(14)` | 0 |
| S3 | `Close ≥ ราคา swing low` (ปิดกลับเหนือ) | — |
| S4 | (ถ้าเปิด) แท่งปัจจุบันเป็นแท่งเขียว | ปิด |

### การจัดการรายการ swing

| รหัส | กฎ |
|---|---|
| S3x | ถ้าแท่งไหน **ปิด**ทะลุ swing (Close > swing high / Close < swing low) = breakout จริง → ลบ swing นั้น ไม่นับเป็น SFP |
| S5 | swing ที่เก่ากว่า `sfpLookback` แท่ง (ค่าเริ่มต้น 100) → ลบ |
| S6 | swing ที่ถูก SFP ไปแล้ว → ลบ (ใช้ได้ครั้งเดียว) |
| — | ถ้าแท่งเดียวกวาดหลาย swing พร้อมกัน → วาดเส้นไปที่ swing ที่ไกลที่สุด (สูงสุด/ต่ำสุด) และติดป้าย SFP ป้ายเดียว |

การแสดงผล: เส้นประจาก swing ถึงแท่ง SFP + ป้าย "SFP" เหนือ/ใต้แท่ง

## 4) โหมด Debug — ใช้ตอนไล่ดูทีละแท่ง

เปิด **"แสดงค่าอัตราส่วนไส้เทียนที่ทุก pivot"** จะมีป้ายที่ทุก pivot เช่น

```
PH W/B=2.31 W/R=0.62 ✔RJB
PL W/B=0.80 W/R=0.35 ✘
```

- `W/B` = ไส้ / เนื้อเทียน (เทียบกับ R2) — 999 แปลว่าแท่งไม่มีเนื้อ (doji)
- `W/R` = ไส้ / ทั้งแท่ง (เทียบกับ R3)
- `✔RJB` = ผ่านทุกเงื่อนไข, `✘` = ไม่ผ่าน

**วิธีแก้แบบแท่งต่อแท่ง:** ใช้ Bar Replay ใน TradingView เดินทีละแท่ง ดูป้าย Debug แล้วเทียบกับตารางด้านบนว่าแท่งที่คุณคิดว่า "ควรเป็น RJB" ตกเงื่อนไขข้อไหน จากนั้นปรับค่า input หรือแก้บรรทัดที่มีรหัสนั้นในโค้ด
