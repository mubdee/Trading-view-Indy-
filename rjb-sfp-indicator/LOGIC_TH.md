# โค้ดฉบับภาษาไทย (RJB_SFP.pine)

ไฟล์นี้แปลโค้ด `RJB_SFP.pine` เป็นภาษาไทยทีละขั้น **แก้ข้อความในไฟล์นี้ได้เลย**
แล้วบอก Claude ให้ "แปลง LOGIC_TH.md เป็นโค้ด" ระบบจะแก้ `RJB_SFP.pine` ให้ตรงกัน

เลขข้อ (เช่น `2.3b`) มีอยู่ในคอมเมนต์ของโค้ดด้วย — ค้นหาเลขข้อในโค้ดจะเจอบรรทัดที่ตรงกัน

วิธีแก้:
- เปลี่ยนตัวเลข → แก้ตัวเลขในวงเล็บ `(ค่าเริ่มต้น …)`
- เพิ่มเงื่อนไข → เพิ่มบรรทัด `และ …` ใต้ข้อที่ต้องการ
- ตัดเงื่อนไข → ขีดฆ่า `~~แบบนี้~~` หรือเขียน `(ตัดออก)`
- ไม่แน่ใจ → เขียน `?? คำถาม` ไว้ได้

คำย่อที่ใช้:
- **แท่งปัจจุบัน** = แท่งที่พึ่งปิด
- **แท่ง pivot** = แท่งที่ถูกยืนยันว่าเป็นจุดกลับตัว (อยู่ย้อนหลัง N แท่ง)
- **แท่งกวาด (sweep)** = แท่งที่ไส้ทะลุ swing แต่ราคาปิดกลับเข้ามา
- **แท่งยืนยัน** = แท่งที่ราคาปิดทะลุ swing ฝั่งตรงข้าม หลังจากมีแท่งกวาด
- **เนื้อเทียน** = |ราคาปิด − ราคาเปิด|
- **ความยาวแท่ง** = High − Low
- **ไส้บน** = High − (ราคาที่สูงกว่าระหว่าง เปิด/ปิด)
- **ไส้ล่าง** = (ราคาที่ต่ำกว่าระหว่าง เปิด/ปิด) − Low

## ภาพรวม (Bearish — ฝั่ง Bullish กลับด้าน)

```
1. มี Swing High เดิม
2. แท่งกวาด: ไส้ทะลุ Swing High แต่ราคาปิดไม่ทะลุ      → "รอยืนยัน" (จำ Low ของแท่งกวาดเป็นเส้นยืนยัน)
3. ภายใน 40 แท่ง มีแท่งที่ราคาปิดหลุดเส้นยืนยัน         → ✔ SFP
   + ถ้าไส้แท่งกวาดยาวพอ                                → ✔ วาดกล่อง RJB ที่ไส้บนของแท่งกวาด
4. ถ้าราคาปิดเหนือ High ของแท่งกวาดก่อน                 → ✘ ยกเลิก
```

## ส่วนที่ 0 — ค่าตั้งต้น (Inputs)

**Swing / Pivot**
- 0.1 จำนวนแท่งด้านซ้ายของ pivot (ค่าเริ่มต้น 5)
- 0.2 จำนวนแท่งด้านขวาที่ใช้ยืนยัน pivot (ค่าเริ่มต้น 3)

**Rejection Block**
- 0.3 แสดง RJB หรือไม่ (ค่าเริ่มต้น แสดง) แสดงเป็นกล่องตรงไส้เทียนของแท่งกวาด
- 0.3b ยืดกล่องไปทางขวากี่แท่ง นับจากแท่งกวาด (ค่าเริ่มต้น 10)
- 0.4 [R2] ไส้ของแท่งกวาดต้องยาวกว่าเนื้อเทียนอย่างน้อยกี่เท่า (ค่าเริ่มต้น 1.0)
- 0.5 [R3] ไส้ของแท่งกวาดต้องยาวอย่างน้อยกี่ส่วนของความยาวแท่ง (ค่าเริ่มต้น 0.4 = 40%)
- 0.6 [R4] บังคับสีแท่งกวาดหรือไม่ (ค่าเริ่มต้น ไม่บังคับ)
- 0.7 [R6] ยกเลิกโซนแบบ 2 ขั้น: ไส้ทะลุ = โซนจาง, ราคาปิดทะลุ = โซนจางมาก (ไม่ลบ ให้เห็นประวัติ)
- 0.8 [R5] เก็บโซนไว้หลังราคาแตะหรือไม่ (ค่าเริ่มต้น เก็บ)
- 0.9 เก็บโซนสูงสุดกี่โซนต่อฝั่ง (ค่าเริ่มต้น 10)
- 0.10 สีโซน: Bullish = เขียวอมฟ้า, Bearish = แดง, ถูกแตะแล้ว = เทา, ไส้ทะลุแล้ว = เทาจาง, ราคาปิดทะลุแล้ว = เทาจางมาก

**SFP**
- 0.11 แสดง SFP (เส้น + ป้าย) หรือไม่ (ค่าเริ่มต้น แสดง) — ถ้าปิด การคำนวณยังทำงานอยู่ เพราะ RJB ต้องใช้
- 0.12 [S5] swing มีอายุได้นานสุดกี่แท่ง (ค่าเริ่มต้น 100)
- 0.13 [S2] ไส้ต้องทะลุ swing อย่างน้อยกี่เท่าของ ATR(14) (ค่าเริ่มต้น 0 = ทะลุนิดเดียวก็นับ)
- 0.14 [S4] บังคับสีแท่งยืนยันหรือไม่ (ค่าเริ่มต้น ไม่บังคับ)
- 0.16 ต้องยืนยันภายในกี่แท่งหลังแท่งกวาด (ค่าเริ่มต้น 40)

**Debug**
- 0.15 แสดงป้ายค่าไส้เทียนที่แท่งกวาดทุกแท่งหรือไม่ (ค่าเริ่มต้น ไม่แสดง)

## ส่วนที่ 1 — หา Pivot

ทำทุกแท่ง:

- 1.1 ถ้าแท่งที่อยู่ย้อนหลัง (0.2) แท่ง มี High สูงที่สุด เมื่อเทียบกับ (0.1) แท่งทางซ้าย และ (0.2) แท่งทางขวา
  → แท่งนั้นคือ **Swing High**
- 1.2 ถ้าแท่งที่อยู่ย้อนหลัง (0.2) แท่ง มี Low ต่ำที่สุด เมื่อเทียบกับ (0.1) แท่งทางซ้าย และ (0.2) แท่งทางขวา
  → แท่งนั้นคือ **Swing Low**

## ส่วนที่ 2 — SFP (กวาด → ยืนยัน)

### 2A. Bearish SFP (กวาดเหนือ Swing High)

ไล่ดู Swing High ทุกตัวที่เก็บไว้:

- 2.1 [S5] ถ้า swing นี้เก่ากว่า (0.12) แท่ง → ลบทิ้ง
- 2.2 [S3x] ถ้า **ราคาปิด** แท่งปัจจุบัน สูงกว่า swing → เบรกจริง ไม่ใช่การกวาด → ลบทิ้ง
- 2.3a **แท่งกวาด** ถ้า
  - [S1] High แท่งปัจจุบัน สูงกว่า swing
  - และ [S2] ระยะที่ทะลุ (High − swing) ≥ (0.13) × ATR(14)
  - และ [S3] ราคาปิดไม่สูงกว่า swing (ผ่านข้อ 2.2 มาแล้ว)

  → แท่งนี้เป็นแท่งกวาด → จำ เปิด/สูง/ต่ำ/ปิด ของแท่งนี้
  → จำ **Low ของแท่งกวาด** เป็น "เส้นยืนยัน"
  → [S6] ลบ swing ที่ถูกกวาดทิ้ง (ใช้ได้ครั้งเดียว)
  → สถานะ = **รอยืนยัน**
- 2.3b **ยืนยัน** ถ้าภายใน (0.16) แท่งนับจากแท่งกวาด มีแท่งที่ **ราคาปิด < เส้นยืนยัน** (ราคากลับมาทะลุ Low ของแท่งกวาดด้วยเนื้อเทียน)
  → **เจอ Bearish SFP**
  → ถ้าเกิน (0.16) แท่งแล้วยังไม่ยืนยัน → ทิ้ง
- 2.3c **ยกเลิก** ถ้าระหว่างรอ มีแท่งที่ราคาปิด > High ของแท่งกวาด → ทิ้ง
- 2.3d ถ้าระหว่างรอ เกิดแท่งกวาดใหม่ → ใช้แท่งกวาดใหม่แทนตัวเดิม

### 2B. Bullish SFP (กวาดใต้ Swing Low)

- 2.4 [S5] ถ้า swing low เก่ากว่า (0.12) แท่ง → ลบทิ้ง
- 2.5 [S3x] ถ้า **ราคาปิด** ต่ำกว่า swing → เบรกจริง → ลบทิ้ง
- 2.6a **แท่งกวาด** ถ้า Low ต่ำกว่า swing และระยะทะลุ ≥ (0.13) × ATR และราคาปิดไม่ต่ำกว่า swing
  → จำแท่งนี้ + จำ **High ของแท่งกวาด** เป็นเส้นยืนยัน → รอยืนยัน
- 2.6b **ยืนยัน** ถ้าภายใน (0.16) แท่ง มีแท่งที่ **ราคาปิด > เส้นยืนยัน** (ราคากลับมาทะลุ High ของแท่งกวาดด้วยเนื้อเทียน)
  → **เจอ Bullish SFP**
- 2.6c **ยกเลิก** ถ้าราคาปิด < Low ของแท่งกวาด
- 2.6d เกิดแท่งกวาดใหม่ → ใช้ตัวใหม่แทน

### 2C. กรองสีแท่ง และวาด

- 2.7 [S4] ถ้าเปิดข้อ (0.14):
  - Bearish: แท่งยืนยันต้องเป็นแท่งแดง (ปิด < เปิด)
  - Bullish: แท่งยืนยันต้องเป็นแท่งเขียว (ปิด > เปิด)
- 2.8 ถ้าเปิดข้อ (0.11) → วาดเส้นประจากเส้นยืนยัน (Low/High ของแท่งกวาด ที่ถูกทะลุด้วยเนื้อเทียน) ถึงแท่งยืนยัน + ป้าย "SFP" (Bearish อยู่เหนือแท่ง, Bullish อยู่ใต้แท่ง)

### 2D. เก็บ swing ใหม่

- 2.9 ถ้าข้อ 1.1 เจอ Swing High ใหม่ → เพิ่มเข้ารายการ (ไม่เกิน 50 ตัว)
- 2.10 ถ้าข้อ 1.2 เจอ Swing Low ใหม่ → เพิ่มเข้ารายการ (ไม่เกิน 50 ตัว)
- (ทำหลังสุด เพื่อไม่ให้ swing ที่เพิ่งยืนยันถูกใช้ในแท่งเดียวกัน)

## ส่วนที่ 3 — จัดการโซน RJB เดิม

ทำทุกแท่ง ก่อนสร้างโซนใหม่ (โซนใหม่จึงเริ่มเช็คตั้งแต่แท่งถัดไป):

**โซน Bearish (แนวต้าน)**
- 3.1 [R6] ยกเลิก 2 ขั้น
  - ขั้นที่ 1: High > ขอบบนโซน → โซนเปลี่ยนเป็นสีเทาจาง
  - ขั้นที่ 2: ราคาปิด > ขอบบนโซน → โซนจางมาก และเลิกติดตาม (กล่องยังอยู่บนกราฟ)
- 3.2 [R5] ถ้า High ≥ ขอบล่างโซน และยังไม่เคยถูกแตะ
  → ทำเครื่องหมาย "ถูกแตะแล้ว" + alert "แตะ Bearish RJB"
  → ถ้าข้อ (0.8) = เก็บ: เปลี่ยนเป็นสีเทา (ถ้ายังไม่จาง) / ถ้าไม่เก็บ: ลบโซน

**โซน Bullish (แนวรับ)**
- 3.3 [R6] ยกเลิก 2 ขั้น
  - ขั้นที่ 1: Low < ขอบล่างโซน → โซนจาง
  - ขั้นที่ 2: ราคาปิด < ขอบล่างโซน → โซนจางมาก และเลิกติดตาม
- 3.4 [R5] ถ้า Low ≤ ขอบบนโซน และยังไม่เคยถูกแตะ → เหมือนข้อ 3.2

## ส่วนที่ 4 — สร้างโซน RJB (เกิดตอน SFP ยืนยัน)

### Bearish RJB — ต้องผ่าน **ทุกข้อ**
- 4.1 Bearish SFP ได้รับการยืนยัน (ข้อ 2.3b)
- 4.2 ไส้บนของ **แท่งกวาด** ยาวพอ
  - ความยาวแท่ง > 0
  - [R2] ไส้บน ≥ (0.4) × เนื้อเทียน
  - [R3] ไส้บน ÷ ความยาวแท่ง ≥ (0.5)
  - [R4] ถ้าเปิดข้อ (0.6): แท่งกวาดต้องเป็นแท่งแดง
- 4.3 ถ้าผ่าน → วาดกล่องจาก **ราคาที่สูงกว่าระหว่างเปิด/ปิด** ถึง **High** ของแท่งกวาด
  - เริ่มที่แท่งกวาด ยืดไปทางขวา (0.3b) แท่ง (ถ้าแท่งยืนยันอยู่ไกลกว่านั้น กล่องจะยาวถึงแท่งยืนยัน)

### Bullish RJB — ต้องผ่าน **ทุกข้อ**
- 4.5 Bullish SFP ได้รับการยืนยัน (ข้อ 2.6b)
- 4.6 ไส้ล่างของแท่งกวาดยาวพอ ([R2] ≥ (0.4) × เนื้อเทียน, [R3] ≥ (0.5) ของแท่ง, [R4] แท่งเขียวถ้าเปิด)
- 4.7 ถ้าผ่าน → วาดกล่องจาก **Low** ถึง **ราคาที่ต่ำกว่าระหว่างเปิด/ปิด** ของแท่งกวาด ยืดไปขวา (0.3b) แท่ง

### หลังสร้าง
- 4.8 ถ้าจำนวนโซนที่ติดตามอยู่เกิน (0.9) → เลิกติดตามโซนเก่าสุด (กล่องยังอยู่บนกราฟ)
- 4.9 ส่ง alert "Bullish/Bearish RJB ใหม่"

## ส่วนที่ 5 — ป้าย Debug

- 5.1 ถ้าเปิดข้อ (0.15) ทุกครั้งที่เจอแท่งกวาด → ติดป้ายที่แท่งนั้น
  - `W/B` = ไส้ ÷ เนื้อเทียน (999 = แท่งไม่มีเนื้อ)
