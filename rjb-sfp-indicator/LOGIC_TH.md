# โค้ดฉบับภาษาไทย (RJB_SFP.pine)

ไฟล์นี้แปลโค้ด `RJB_SFP.pine` เป็นภาษาไทยทีละขั้น **แก้ข้อความในไฟล์นี้ได้เลย**
แล้วบอก Claude ให้ "แปลง LOGIC_TH.md เป็นโค้ด" ระบบจะแก้ `RJB_SFP.pine` ให้ตรงกัน

วิธีแก้:
- เปลี่ยนตัวเลข → แก้ตัวเลขในวงเล็บ `(ค่าเริ่มต้น …)`
- เพิ่มเงื่อนไข → เพิ่มบรรทัด `และ …` ใต้ข้อที่ต้องการ
- ตัดเงื่อนไข → ขีดฆ่า `~~แบบนี้~~` หรือเขียน `(ตัดออก)`
- ไม่แน่ใจ → เขียน `?? คำถาม` ไว้ได้

คำย่อที่ใช้:
- **แท่งปัจจุบัน** = แท่งที่เพิ่งปิด
- **แท่ง pivot** = แท่งที่ถูกยืนยันว่าเป็นจุดกลับตัว (อยู่ย้อนหลัง N แท่ง)
- **เนื้อเทียน** = |ราคาปิด − ราคาเปิด|
- **ความยาวแท่ง** = High − Low
- **ไส้บน** = High − (ราคาที่สูงกว่าระหว่าง เปิด/ปิด)
- **ไส้ล่าง** = (ราคาที่ต่ำกว่าระหว่าง เปิด/ปิด) − Low

## ส่วนที่ 1 — หา Pivot [P1] · โค้ดบรรทัด 60–75

ทำทุกแท่ง:

- 1.1 ถ้าแท่งที่อยู่ย้อนหลัง (0.2) แท่ง มี High สูงที่สุด เมื่อเทียบกับ (0.1) แท่งทางซ้าย และ (0.2) แท่งทางขวา
  → แท่งนั้นคือ **Swing High**
- 1.2 ถ้าแท่งที่อยู่ย้อนหลัง (0.2) แท่ง มี Low ต่ำที่สุด เมื่อเทียบกับ (0.1) แท่งทางซ้าย และ (0.2) แท่งทางขวา
  → แท่งนั้นคือ **Swing Low**
- 1.3 จำค่า เปิด / สูง / ต่ำ / ปิด ของแท่ง pivot นั้นไว้ แล้วคำนวณ เนื้อเทียน, ความยาวแท่ง, ไส้บน, ไส้ล่าง

## ส่วนที่ 2 — ตรวจ SFP บนแท่งปัจจุบัน · โค้ดบรรทัด 76–134

### 2A. Bearish SFP (กวาดเหนือ Swing High)

ไล่ดู Swing High ทุกตัวที่เก็บไว้ จากใหม่ไปเก่า:

- 2.1 [S5] ถ้า swing นี้เก่ากว่า (0.12) แท่ง → ลบทิ้ง ไปตัวถัดไป
- 2.2 [S3x] ถ้า **ราคาปิด** แท่งปัจจุบัน สูงกว่า swing → ถือว่าเบรกจริง ไม่ใช่ SFP → ลบทิ้ง ไปตัวถัดไป
- 2.3 ถ้า
  - [S1] High แท่งปัจจุบัน สูงกว่า swing
  - และ [S2] ระยะที่ทะลุ (High − swing) ≥ (0.13) × ATR(14)
  - (ผ่านข้อ 2.2 มาแล้ว แปลว่า [S3] ราคาปิดอยู่ไม่สูงกว่า swing)

  → **เจอ Bearish SFP**
  - ถ้าแท่งเดียวกวาดหลาย swing ให้จำตัวที่ **สูงที่สุด**
  - [S6] ลบ swing นี้ทิ้ง (ใช้ได้ครั้งเดียว)

### 2B. Bullish SFP (กวาดใต้ Swing Low)

ไล่ดู Swing Low ทุกตัว จากใหม่ไปเก่า:

- 2.4 [S5] ถ้าเก่ากว่า (0.12) แท่ง → ลบทิ้ง
- 2.5 [S3x] ถ้า **ราคาปิด** ต่ำกว่า swing → เบรกจริง → ลบทิ้ง
- 2.6 ถ้า
  - [S1] Low แท่งปัจจุบัน ต่ำกว่า swing
  - และ [S2] ระยะที่ทะลุ (swing − Low) ≥ (0.13) × ATR(14)

  → **เจอ Bullish SFP**
  - ถ้ากวาดหลายตัว ให้จำตัวที่ **ต่ำที่สุด**
  - [S6] ลบ swing นี้ทิ้ง

### 2C. กรองสีแท่ง และวาด

- 2.7 [S4] ถ้าเปิดข้อ (0.14):
  - Bearish SFP ต้องเป็นแท่งแดง (ปิด < เปิด)
  - Bullish SFP ต้องเป็นแท่งเขียว (ปิด > เปิด)
- 2.8 ถ้าเป็น SFP → วาดเส้นประจาก swing ถึงแท่งปัจจุบัน + ป้าย "SFP" (Bearish อยู่เหนือแท่ง, Bullish อยู่ใต้แท่ง)

### 2D. เก็บ swing ใหม่

- 2.9 ถ้าข้อ 1.1 เจอ Swing High ใหม่ → เพิ่มเข้ารายการ (เก็บไม่เกิน 50 ตัว เกินแล้วลบตัวเก่าสุด)
- 2.10 ถ้าข้อ 1.2 เจอ Swing Low ใหม่ → เพิ่มเข้ารายการ (ไม่เกิน 50 ตัว)
- (ทำหลังข้อ 2.1–2.8 เพื่อไม่ให้ swing ที่เพิ่งเกิดถูกเช็คในแท่งเดียวกัน)

## ส่วนที่ 3 — จัดการโซน RJB เดิม · โค้ดบรรทัด 136–173

ไล่ดูทุกโซนที่มีอยู่ ทำทุกแท่ง:

**โซน Bearish (แนวต้าน)**
- 3.1 [R6] ยกเลิกโซน ถ้า
  - โหมด "ราคาปิด": ราคาปิด > ขอบบนโซน
  - โหมด "ไส้": High > ขอบบนโซน

  → ลบโซน ไปโซนถัดไป
- 3.2 [R5] ถ้า High ≥ ขอบล่างโซน และโซนยังไม่เคยถูกแตะ
  → ทำเครื่องหมายว่า "ถูกแตะแล้ว" + ส่ง alert "แตะ Bearish RJB"
  → ถ้าข้อ (0.8) = เก็บ: เปลี่ยนเป็นสีเทา / ถ้าไม่เก็บ: ลบโซน

**โซน Bullish (แนวรับ)**
- 3.3 [R6] ยกเลิกโซน ถ้า
  - โหมด "ราคาปิด": ราคาปิด < ขอบล่างโซน
  - โหมด "ไส้": Low < ขอบล่างโซน
- 3.4 [R5] ถ้า Low ≤ ขอบบนโซน และยังไม่เคยถูกแตะ → เหมือนข้อ 3.2

**ทุกโซนที่ยังอยู่**
- 3.5 ยืดโซนไปทางขวาถึงแท่งปัจจุบัน

## ส่วนที่ 4 — สร้างโซน RJB ใหม่ · โค้ดบรรทัด 175–195

### Bearish RJB — ต้องผ่าน **ทุกข้อ**
- 4.1 [R1] แท่ง pivot เป็น Swing High (ข้อ 1.1)
- 4.2 ความยาวแท่ง > 0
- 4.3 [R2] ไส้บน ≥ (0.4) × เนื้อเทียน
- 4.4 [R3] ไส้บน ÷ ความยาวแท่ง ≥ (0.5)
- 4.5 [R4] ถ้าเปิดข้อ (0.6): แท่ง pivot ต้องเป็นแท่งแดง
- 4.6 [R7] ถ้าผ่าน → สร้างโซนจาก **ราคาที่สูงกว่าระหว่างเปิด/ปิด** ถึง **High** เริ่มที่แท่ง pivot

### Bullish RJB — ต้องผ่าน **ทุกข้อ**
- 4.7 [R1] แท่ง pivot เป็น Swing Low (ข้อ 1.2)
- 4.8 ความยาวแท่ง > 0
- 4.9 [R2] ไส้ล่าง ≥ (0.4) × เนื้อเทียน
- 4.10 [R3] ไส้ล่าง ÷ ความยาวแท่ง ≥ (0.5)
- 4.11 [R4] ถ้าเปิดข้อ (0.6): แท่ง pivot ต้องเป็นแท่งเขียว
- 4.12 [R7] ถ้าผ่าน → สร้างโซนจาก **Low** ถึง **ราคาที่ต่ำกว่าระหว่างเปิด/ปิด**

### หลังสร้าง
- 4.13 ถ้าจำนวนโซนฝั่งนั้นเกิน (0.9) → ลบโซนเก่าสุด
- 4.14 ส่ง alert "Bullish/Bearish RJB ใหม่"
- (โซนใหม่จะเริ่มเช็คแตะ/ยกเลิกตั้งแต่แท่งถัดไป เพราะส่วนที่ 3 ทำก่อนส่วนที่ 4)
