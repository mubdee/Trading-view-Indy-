# RJB & SFP Indicator (TradingView Pine Script v6)

อินดิเคเตอร์แสดง **Rejection Blocks (RJB)** และ **Liquidity Grabs / Swing Failure Patterns (SFP)**
เขียนขึ้นใหม่ตามแนวคิดที่ Milana Trades ใช้ ไม่ได้คัดลอกโค้ดต้นฉบับมา

## ไฟล์
- `RJB_SFP.pine` — ตัวอินดิเคเตอร์
- `CONDITIONS_TH.md` — ตารางสรุปเงื่อนไขฉบับย่อ
- `LOGIC_TH.md` — โค้ดทั้งไฟล์แปลเป็นภาษาไทยทีละขั้น ใช้แก้ตรรกะเป็นภาษาไทย

## วิธีใช้
1. เปิด TradingView → Pine Editor
2. วางโค้ดจาก `RJB_SFP.pine` → Save → Add to chart
3. ตั้ง alert จากเมนู Alert → เลือก condition ของ "RJB/SFP"
